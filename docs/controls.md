# Controls Reference — Tower Defense: Last Grid

## Keyboard & Mouse Controls

| Action | Primary Key | Secondary / Mouse | Description |
|---|---|---|---|
| Select Tower 1 (Pulse) | `1` | Click Build Bar | Select Pulse Tower for placement |
| Select Tower 2 (Mortar) | `2` | Click Build Bar | Select Mortar Tower for placement |
| Select Tower 3 (Cryo) | `3` | Click Build Bar | Select Cryo Tower for placement |
| Select Tower 4 (Railgun) | `4` | Click Build Bar | Select Railgun Tower for placement |
| Select Tower 5 (Beacon) | `5` | Click Build Bar | Select Beacon Tower for placement |
| Place Tower | Left Click | Enter / Space | Confirm placement on highlighted cell |
| Cancel Build / Deselect | Right Click | `Esc` | Cancel ghost placement or clear selection |
| Start Wave / Early Call | `Space` | Click Wave Button | Start wave early during build countdown |
| Pause / Resume | `Esc` / `P` | Click Pause Button | Freeze gameplay, open pause menu |
| Upgrade Selected Tower | `U` | Click Upgrade | Upgrade tower to next tier |
| Sell Selected Tower | `S` | Click Sell | Sell tower for 70% refund |
| Cycle Targeting Priority | `T` | Click Target Button | Cycle FIRST -> LAST -> STRONGEST -> NEAREST |
| Toggle Game Speed | `Tab` | Click Speed Button | Toggle game simulation speed (1x -> 2x -> 3x) |

## Touch Controls (Mobile / Tablets)
- **Tap Build Icon**: Selects tower and shows ghost preview.
- **Drag & Drop**: Drag tower icon onto grid cell to position.
- **Tap Cell**: Tap to inspect placed tower or confirm ghost.
- **Pinch-to-Zoom**: Adjust camera view (0.75x to 1.5x zoom range).
- **Two-Finger Pan**: Move camera around the battlefield.
- **Android Back Button**: Triggers Pause or returns to previous menu.
