# Mixamo CS2 SWAT FBX Fayllari

Ushbu papkaga Mixamo'dan (yoki boshqa 3D manbadan) olingan quyidagi `.fbx` fayllarini joylashtirishingiz mumkin:
1. `idle.fbx` — Asosiy personaj meshi va turg'un holat (Idle) animatsiyasi.
2. `walk.fbx` — Qadam tashlash (Walk) animatsiyasi.
3. `run.fbx` — Yugurish (Run) animatsiyasi.
4. `jump.fbx` — Sakrash (Jump) animatsiyasi.

**Eslatma:** Agar `idle.fbx` ushbu papkaga yuklansa, veb-studiya avtomatik ravishda ushbu Mixamo SWAT modelini yuklaydi. Agar fayllar hali yuklanmagan bo'lsa, tizim zaxiradagi professional `soldier_real.glb` modelini darhol jonli ishlatadi.
