# Tower Defense: Last Grid

A 2D wave-based tower defense strategy game built with Godot 4 (Compatibility renderer) in typed GDScript.

## Features
- **10 Distinct Maps** with unique themes, route layouts, and modifiers.
- **5 Tower Archetypes**: Pulse (rapid fire), Mortar (area splash), Cryo (slowing field), Railgun (piercing sniper), and Beacon (support aura).
- **8 Enemy Archetypes & 3 Bosses**: Dynamic path routing, shields, armor mechanics, and special abilities.
- **30 Wave Configurations**: Scaling encounters, boss waves, and tactical challenges.
- **Meta-progression**: Research points and persistent skill trees across Offense, Economy, and Defense.
- **Cross-platform**: Support for Web (HTML5), Desktop, and Mobile (Android).

## Quick Start
### Prerequisites
- Godot 4.3+ (Compatibility renderer recommended)

### Running Locally
```bash
godot --path .
```

### Running Headless Tests
```bash
godot --headless -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit
```
